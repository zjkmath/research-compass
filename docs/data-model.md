# Data and evidence

Organizations, people, formal visit paths, mentor targets, specific opportunities, program rounds and funding relations are distinct. Directory records do not create recruitment claims. Priority-20 is an instance discovery boundary with grandfathered existing records; the public registry contains twenty fictional institutions.

Public-facing facts carry provenance and field verification state. Proposals preserve observed changes and conflicts until explicit review. Fetch time, content observation time, publication time and human verification time have separate meanings. An old approved fingerprint is not automatically the current effective reviewed version.

UserRecord, TargetRecord, SavedFilter, LocalProfile, DecisionRecord and PathSupport are private and user-scoped. Comparisons and budgets retain inputs and factual versions so changes can invalidate old decisions. Grants and personal support are separate, and comparable cash requires explicit basis. Synthetic seed fixtures contain none of these private records and no auth users.
