# Privacy boundary

The public repository ships source and fictional data only. It contains no private user database, profile, favorites, notes, saved filter, follow-up, budget, account, key, production configuration or infrastructure inventory. Those remain in separately protected state directories.

Do not upload private exports or troubleshooting dumps to public issues. Review both filenames and file contents before sharing. A `.gitignore` does not remove an already tracked secret. Audit `git ls-files` and full history before release.

Contact preparation stays in the user's private workspace; the application does not send email or submit applications. Collection must respect source permissions and should not transmit user profiles. No analytics or paid model service is configured by the demo.
